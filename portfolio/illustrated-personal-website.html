Gamefied Website

Project type

Browser-based Gamified Portfolio. A navigable 2D street environment where each shop represents a content section, balancing immersive exploration with fast-track access.

Role

End-to-end Product Designer (UX Strategy, Information Architecture, Interaction Design, Custom Illustrations, Rive Animations, UI Design System, Copywriting, Prototyping).

Outcomes

Reduced average task completion time by 75% (~5:40 → ~1:20) across two testing rounds.
Validated dual-navigation concept, proving engagement without sacrificing usability.

Under the Hood

A gamified world still needs strict rules.

Explore a 65+ component Design System built for a navigable 2D environment. Color palette, layout logic, and responsive breakpoints engineered to keep the game-like experience consistent without breaking accessibility.

Open Design System

Gamification without strategy is just a toy.

I mapped every user decision before writing a single line of code. Dual-navigation strategy (exploration vs. fast-track), 6-phase user flow, and behavioral loops designed to balance immersion with monster efficiency.

Explore UX Strategy

Scalability isn't optional, even in a game.

A 65+ component library with atomic structure and strict governance. Information architecture documented across all breakpoints, ensuring the experience scales from mobile to desktop without losing the narrative thread.

Inspect the library

Motion that serves the user, not the ego.

From WASD character movement to the Steam mini-game mechanic, every interaction was built in-line with performance and accessibility in mind. Validated with users who don't play games.
